# milaklingbeil.de

Portfolio website for Mila Klingbeil, a creative. Live at [milaklingbeil.de](https://milaklingbeil.de).

This is the first website I designed, built and launched on my own, from the first line of code to going live.

## Tech Stack

- [Nuxt](https://nuxt.com/) for the framework and routing
- [Vue.js](https://vuejs.org/) for the components
- [Tailwind CSS](https://tailwindcss.com/) for styling
- [TypeScript](https://www.typescriptlang.org/) for type-safe code


## What I Learned

- Building a full website with Nuxt and Vue and structuring it into reusable components
- Styling responsive layouts with Tailwind CSS
- Using TypeScript in a frontend project
- Taking a project from idea to a live, publicly accessible website
